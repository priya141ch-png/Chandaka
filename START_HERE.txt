================================================================================
                    3 SIMPLE STEPS TO GET APK
================================================================================

STEP 1: Create Free GitHub Account
───────────────────────────────────
Go to: https://github.com/signup
Takes: 2 minutes


STEP 2: Upload Your Project
────────────────────────────
1. Go to https://github.com/new
2. Name it "Chandaka"
3. Make it Public (important!)
4. Create repository
5. Click "Add file" → "Upload files"
6. Select files from C:\Users\swath\FinanceApp\
7. Upload everything EXCEPT:
   - node_modules/
   - android/build/
   - android/.gradle/
8. Click "Commit changes"

Takes: 2-3 minutes


STEP 3: Wait for Automatic Build
─────────────────────────────────
1. Click "Actions" tab in GitHub
2. Watch the build progress
3. Wait for GREEN ✅ checkmark
4. Click the build
5. Scroll to "Artifacts"
6. Download "app-release"

Takes: 10-15 minutes


================================================================================
                    INSTALL ON YOUR PHONE
================================================================================

BEFORE INSTALLING:
Go to Settings → Security → "Unknown Sources" = ON


INSTALLATION:
1. Transfer app-release.apk to your phone
   Options:
   - Copy via USB cable to Downloads folder
   - Email to yourself and download
   - Upload to Google Drive and download

2. On phone: Open Files → Downloads

3. Tap app-release.apk

4. Tap "Install"

5. Wait for completion

6. Look for "Chandaka" icon on home screen

7. Tap to open and enjoy!

================================================================================
                   TROUBLESHOOTING
================================================================================

Problem: Build taking too long
Solution: First build downloads dependencies (takes 10-15 min normally)

Problem: Can't find Actions tab
Solution: Make sure repository is public, refresh page

Problem: APK not in artifacts
Solution: Wait 15 minutes, check if build has green checkmark

Problem: Can't transfer APK to phone
Solution: Try different method - USB cable, email, or cloud storage

Problem: App won't install
Solution: Enable "Unknown Sources" in Settings → Security
