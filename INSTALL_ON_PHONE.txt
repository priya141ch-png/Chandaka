================================================================================
                    FINANCE APP - BUILD & INSTALL GUIDE
================================================================================

IMPORTANT: You MUST have these installed first:
  ✓ Node.js (https://nodejs.org/)
  ✓ Java JDK 11+ (https://www.oracle.com/java/)
  ✓ Android Studio (https://developer.android.com/studio)

To check if installed, run in PowerShell:
  node -v
  java -version

================================================================================
                              BUILD APK (10 steps)
================================================================================

STEP 1: Open PowerShell and go to project folder
────────────────────────────────────────────────
cd C:\Users\swath\FinanceApp


STEP 2: Install all dependencies (takes 2-3 minutes first time)
──────────────────────────────────────────────────────────────
npm install


STEP 3: Find your Android SDK location
───────────────────────────────────────
Open Android Studio → File → Project Structure
Copy the Android SDK Location (usually: C:\Users\YOUR_USERNAME\AppData\Local\Android\Sdk)


STEP 4: Create local.properties file in android folder
───────────────────────────────────────────────────────
echo sdk.dir=C:\Users\YOUR_USERNAME\AppData\Local\Android\Sdk > android\local.properties

Replace YOUR_USERNAME with your Windows username!

Example:
echo sdk.dir=C:\Users\swath\AppData\Local\Android\Sdk > android\local.properties


STEP 5: Create signing key (press Enter for all, type 123456 when asked for password)
─────────────────────────────────────────────────────────────────────────────────────
keytool -genkey -v -keystore my-release-key.keystore -keyalg RSA -keysize 2048 -validity 10000 -alias my-key-alias

Password: 123456
Key Password: 123456
Rest: Just press Enter


STEP 6: Go to android folder
────────────────────────────
cd android


STEP 7: Build the APK (THIS TAKES 5-10 MINUTES - BE PATIENT!)
─────────────────────────────────────────────────────────────
./gradlew assembleRelease

WAIT FOR: "BUILD SUCCESSFUL" message


STEP 8: Go back to project folder
──────────────────────────────────
cd ..


STEP 9: Find your APK file
──────────────────────────
Your APK is at:
C:\Users\swath\FinanceApp\android\app\build\outputs\apk\release\app-release.apk

Copy this file to your Desktop or Downloads folder


STEP 10: Done! Move to PHONE INSTALLATION section below
────────────────────────────────────────────────────────


================================================================================
                          INSTALL ON ANDROID PHONE
================================================================================

REQUIREMENT: Enable "Unknown Sources" in your phone settings first

Phone Setup:
1. Go to Settings
2. Tap "Security" or "Apps & permissions"
3. Find "Unknown Sources" or "Install from unknown sources"
4. Turn it ON


INSTALLATION METHOD A: Using USB Cable (RECOMMENDED)
─────────────────────────────────────────────────

1. Connect your Android phone to computer via USB cable
2. Copy app-release.apk to phone's internal storage (Downloads folder)
   - On computer: Right-click APK → Copy
   - On phone: Open Files/File Manager → Paste in Downloads
3. On your phone:
   - Open Files/File Manager
   - Go to Downloads folder
   - Tap "app-release.apk"
   - Tap "Install"
   - Wait for installation to complete
4. Look for "Finance App" icon on your home screen
5. Tap to open and enjoy!


INSTALLATION METHOD B: Using Email
────────────────────────────────

1. On computer: Right-click APK → Send to → Mail recipient
   OR attach to email and send to yourself
2. On phone: Open email and download attachment
3. Tap downloaded APK
4. Tap "Install"
5. Done!


INSTALLATION METHOD C: Using Cloud Storage
─────────────────────────────────────────

1. Upload APK to Google Drive or OneDrive
2. On phone: Download from cloud storage
3. Tap downloaded APK
4. Tap "Install"
5. Done!

================================================================================
                         TROUBLESHOOTING
================================================================================

Problem: Build fails with "SDK not found"
─────────────────────────────────────────
Solution:
1. Open Android Studio
2. File → Project Structure
3. Copy the Android SDK Location
4. Run: echo sdk.dir=YOUR_COPIED_PATH > android\local.properties


Problem: "Java not found" error
────────────────────────────────
Solution:
1. Download Java JDK from: https://www.oracle.com/java/
2. Install it
3. Restart PowerShell
4. Try building again


Problem: npm install hangs or fails
───────────────────────────────────
Solution:
npm cache clean --force
npm install


Problem: Build takes too long
──────────────────────────────
Don't interrupt! First build downloads dependencies (5-10 min normal)
If still building after 15 min:
1. Stop (Ctrl+C)
2. Delete android/build and android/.gradle folders
3. Try again: ./gradlew clean && ./gradlew assembleRelease


Problem: App crashes after installation
─────────────────────────────────────────
Solution:
1. Uninstall app
2. Clear phone's app cache (Settings → Apps → Finance App → Storage → Clear Cache)
3. Reinstall APK


Problem: Can't find the APK file
─────────────────────────────────
It's at:
C:\Users\swath\FinanceApp\android\app\build\outputs\apk\release\app-release.apk

OR search for "app-release.apk" in Windows Explorer
