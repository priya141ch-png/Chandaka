## 🚀 3-Step Deployment (20 minutes)

### STEP 1: Create GitHub Account & Repository

1. Go to https://github.com/signup
2. Create account (takes 2 minutes)
3. Go to https://github.com/new
4. Create repository:
   - **Name:** Chandaka
   - **Description:** Professional financial management app
   - **Public** ✅ (important)
   - Click **Create repository**

---

### STEP 2: Upload Project Files

**EASIEST METHOD - No Command Line:**

1. In your repository, click **"Add file" → "Upload files"**
2. Open file explorer: `C:\Users\swath\FinanceApp\`
3. Select and upload:
   ```
   ✅ .github/ folder (has build configuration)
   ✅ src/ folder (all screens and code)
   ✅ android/ folder (entire folder)
   ✅ App.js
   ✅ index.js
   ✅ app.json
   ✅ package.json
   ✅ babel.config.js
   ✅ metro.config.js
   ✅ README.md
   ```

4. **DO NOT upload:**
   ```
   ❌ node_modules/
   ❌ android/build/
   ❌ android/.gradle/
   ❌ .git/
   ```

5. Click **"Commit changes"**

---

### STEP 3: Wait for Automatic Build

1. Click **"Actions"** tab in your repository
2. Wait for build to complete (10-15 minutes)
3. Look for **green ✅ checkmark** = Success
4. Click the successful build
5. Scroll down to **"Artifacts"**
6. Click **"app-release"** to download APK

---

## 📥 After Download: Install on Phone

### Enable Installation

1. On your phone: **Settings → Security → Unknown Sources** = ON

### Install APK

**Option A: USB Cable**
1. Connect phone to computer
2. Copy downloaded `app-release.apk` to phone's Downloads
3. On phone: Open Files → Downloads
4. Tap `app-release.apk`
5. Tap **Install**

**Option B: Email to Yourself**
1. Email the APK to your email
2. Open email on phone
3. Download attachment
4. Tap to install

**Option C: Cloud Storage**
1. Upload to Google Drive/OneDrive
2. Download from phone
3. Tap to install

## 🔧 Troubleshooting

### Build Takes Too Long (>20 min)
- First build is slower (downloads dependencies)
- Check Actions tab for progress
- Usually completes in 15 min

### APK Not Showing in Artifacts
- Wait 15 minutes for build to complete
- Check if build has green ✅ checkmark
- Refresh the page

### Build Shows Red ❌ Error
- Check the error log in Actions tab
- Usually temporary issue
- Try re-running the build

### Can't Install APK on Phone
- Enable "Unknown Sources" in Settings
- Make sure phone has enough storage (200MB+)
- Try a different transfer method (USB, email, cloud)
