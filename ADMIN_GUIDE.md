# Admin Panel Guide

## Quick Access

**Location:** More Tab → Admin Panel Button

**Password:** `12345`

---

## Features Overview

### 1. Manage Credit Cards

**What you can do:**
- View all credit cards
- Add new credit cards
- Delete existing cards
- Customize card colors

**Card Information Required:**
- Bank Name (e.g., HDFC Bank, Axis Bank)
- Card Number (e.g., XXXX XXXX XXXX 7539)
- Due Amount (e.g., ₹50,000)
- Due Date (e.g., DUE IN 5 DAYS)
- Card Color (choose from 5 color options)

**Example:**
```
Bank Name: ICICI Bank
Card Number: XXXX XXXX XXXX 8901
Due Amount: ₹35,000
Due Date: DUE IN 10 DAYS
Card Color: Blue
```

---

### 2. Manage Personal Loans

**What you can do:**
- View all active loans
- Add new loans
- Delete loan records
- Track EMI details

**Loan Information Required:**
- Loan Type (e.g., Personal Loan, Home Loan)
- Provider (e.g., HDFC Bank, SBI)
- Loan Amount (e.g., ₹10,00,000)
- EMI Amount (e.g., ₹15,234)
- Remaining Amount (e.g., ₹2,50,000)
- Next EMI Date (e.g., 2026-09-05)

**Example:**
```
Loan Type: Auto Loan
Provider: ICICI Bank
Loan Amount: ₹8,00,000
EMI Amount: ₹12,500
Remaining Amount: ₹3,50,000
Next EMI Date: 2026-09-10
```

---

### 3. Manage Bank Accounts

**What you can do:**
- View all bank accounts
- Add new bank accounts
- Delete accounts
- Track account details

**Bank Account Information Required:**
- Bank Name (e.g., State Bank of India)
- Account Type (e.g., Savings, Current)
- Account Number (e.g., XXXX XXXX 1234)
- Balance (e.g., ₹5,00,000)
- IFSC Code (e.g., SBIN0001234)

**Example:**
```
Bank Name: Kotak Bank
Account Type: Savings
Account Number: XXXX XXXX 9876
Balance: ₹12,50,000
IFSC Code: KKBK0001234
```

## Step-by-Step Instructions

### Add a Credit Card

1. Open the app
2. Navigate to **More** tab
3. Tap **Admin Panel**
4. Enter password: `12345`
5. Tap **Manage Credit Cards**
6. See the list of existing cards
7. Close modal and go back to Cards tab
8. Tap the **+** (plus) button at the bottom right
9. Fill in card details
10. Select card color
11. Tap **Add Card**

### Delete a Credit Card

1. Open the app
2. Navigate to **More** tab
3. Tap **Admin Panel**
4. Enter password: `12345`
5. Tap **Manage Credit Cards**
6. Find the card you want to delete
7. Tap the **trash icon** on the right
8. Confirm deletion

### Add a Personal Loan

1. Open the app
2. Navigate to **More** tab
3. Tap **Admin Panel**
4. Enter password: `12345`
5. Tap **Manage Personal Loans**
6. Currently, you'll see existing loans
7. To add: Go back and use the Add button from relevant screen
8. Fill in loan details
9. Tap **Add Loan**

### Add a Bank Account

1. Open the app
2. Navigate to **More** tab
3. Tap **Admin Panel**
4. Enter password: `12345`
5. Tap **Manage Bank Accounts**
6. View existing accounts
7. To add: Tap the Add button from Home screen
8. Fill in account details
9. Tap **Add Account**

## Tips

✅ All changes are saved locally on your phone
✅ Deleting data cannot be undone (no trash/recycle)
✅ Colors are stored for each card
✅ You can add unlimited cards, loans, and accounts
✅ All amounts should be entered with Indian Rupee symbol (₹) for display
✅ Dates should follow the format: YYYY-MM-DD or descriptive (DUE IN X DAYS)

## Logout Admin Mode

After you're done managing data:

1. Tap the **Logout** button (appears in admin section)
2. Admin mode will be deactivated
3. You'll return to normal user mode
